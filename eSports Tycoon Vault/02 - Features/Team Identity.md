# Team Identity (names, logos, jerseys)

## Name
- Player can type a custom team name + 3–4 letter tag (**must pass Roblox `TextService:FilterStringAsync`**).
- "Randomize" button using generator: `[Adjective] [Noun]` → Neon Wolves, Crimson Vortex, Pixel Reapers, Static Drift.
- Naming happens in the tutorial with a ready-made auto-name; rename is free until Stage 2, then costs a small Robux price ([[Tutorial & Onboarding]]).

## Logo
Pick shape + icon + 2 colors (+ unlock decals via cases/achievements).

## Jersey
Template slots: body pattern, sleeve, sponsor patches (sponsors add logos automatically), number/nickname.
Applied to avatars of roster NPCs and the player's avatar.
Garments grow with the HQ (garage tees → practice tops → real jerseys → stage kits) and colors are free to change at any time: [[Jersey Progression]].

## Where it shows
Scoreboard, tournament bracket, HQ banner, clip thumbnails, leaderboards, visitors' view.
