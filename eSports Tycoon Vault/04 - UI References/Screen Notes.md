## Screen - Main HUD
Top: Cash, Fame, Followers, Gems pills. Left rail: Roster, Shop, Cases, Clips, Quests. Bottom center: current objective. Right: stage progress bar.

Name field + randomize, tag, logo picker, color pickers, jersey preview (rotating avatar), Confirm.

## Screen - Roster
Grid of player cards (rarity frames), detail drawer with stat bars, trait, contract, actions (Train / Bench / Release / Sell).

## Screen - Tech Shop
Category tabs (CPU, GPU, Monitor…), item cards with stat delta preview, "Equip to station" selector, rotating stock timer.

## Screen - Case Opening
Case select carousel, odds button, open ×1/×5, reveal stage with beams, result card, duplicate→shards conversion, skip.

## Screen - Match HUD
Scoreboard, round timer, kill feed, commentary line, momentum bar, Clip Moment toast.

## Screen - Bracket
Tournament bracket tree with team logos, your path highlighted, prize pool, next match button.

## Screen - Clip Feed
Vertical feed of clip cards (thumbnail, title, views, likes), trending tags row, Upload/Edit button, own-clips tab.
