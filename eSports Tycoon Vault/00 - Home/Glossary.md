# Glossary

| Term | Meaning |
|---|---|
| **OVR** | Overall rating of a player, weighted average of stats by role (see [[Balance Tables]]) |
| **Potential** | Max a player's stats can reach through training; hidden until scouted |
| **Station** | A PC desk a roster player sits at; generates income and gives stat bonuses |
| **Accessory** | Personal gear a player carries (mouse, keyboard, headset, arm sleeve, glasses, lucky charm); +flat points to one stat, more with stickers (see [[Accessories]]) |
| **Admin Abuse** | Free server-wide event run by schedule or by an admin (Cash Rain, Luck Surge…), see [[Admin Abuse Events]] |
| **Time Skip Ticket** | Consumable that finishes one timer (15 min / 1 h / 4 h), see [[Time Skip Tickets]] |
| **Gear Mode** | **Full** (gear counts) or **Pure** (only player power). Ranked is always Pure; scrims can toggle |
| **Pad** | Tycoon buy button on the plot |
| **Era** | HQ visual stage: Garage → Café → Training Center → Gaming House → Studio Campus → Arena (see [[HQ Era Visual Guide]]) |
| **Fame ★** | Gating stat; never spent; earned by wins and clips |
| **Followers 👥** | Fan count; unlocks sponsors and merch income |
| **Gems 💎** | Premium-ish currency; quests, milestones, Robux |
| **Shards** | From duplicate drops; craft chosen items |
| **Legacy Points (LP)** | Earned by rebirth; spent in the perk tree |
| **Pity** | Guaranteed rarity after N opens without one |
| **Furry variant** | Cosmetic animal-person look on 4% of generated players; species rolled from seed |
| **Dev Pity** | Dev Crate counter: a guaranteed dev on the 75th open without one |
| **Clip Moment** | Highlight flagged by the match sim (ace, clutch, comeback…) |
| **Chemistry** | Team bonus from matches played together |
| **Synergy** | Bonus when the roster covers all 5 roles |
| **Scrim** | Practice match, no rank loss |
| **Dev ✦** | Rarity above Mythic for the dev players (3zzy, Philip, appropriateuser). Specialty stats can exceed 99 |
| **CCU** | Concurrent users across all servers; milestones trigger changes (e.g. Dev Crate price, dev boost) |
| **Season** | One calendar month of themed content, see [[Monthly Seasons]] |
| **Season Case** | That month's exclusive case; vaulted when the month ends |
| **Headliner** | The season's Mythic named pro |
| **Sparks** | +1 per Season Case open; 120 claims the headliner |
| **Stage boss** | Tournament or deal that ends a progression stage |
| **Snapshot** | Saved copy of a roster used for async PvP |
| **FTUE** | First-time user experience (first 15 min) |
| **Rival** | Named AI team that follows your story |
| **Player Level** | 1–10 badge from OVR (FACEIT-style), see [[Skill Levels & Ratings]] |
| **Match Rating** | Per-match performance score, 1.00 = average (HLTV-style) |
| **Ladder tier** | Team rank Garage → Legend from Elo rating |
| **Title** | A fictional esports game your team competes in (Aim Arena, Tower Clash…) |
