# Key Players (Common–Epic)

Hand-made players, 2–3 per title per rarity. Everyone else at these rarities is random ([[Player Generator]]). Legendary/Mythic named stars: [[Pro Player References]].

## Rules for key players
- **Fixed:** name, look, vibe, trait, role, story hook.
- **Slightly random:** each copy's stats roll **±3** around the listed values and Potential rolls in a small band, so two copies differ a little (good for trading).
- **Collectible:** each key player has a Collection Log slot ([[Achievements & Collections]]). Collect all key players of one title → title-themed jersey patch.
- **Where they show up:** featured free-agent slot (one per day), case pools (3–10% of that rarity's player drops), AI rival rosters, and story events.
- Traits follow the rarity limits in [[Trait Library]] (Common/Uncommon ⚪ only, Rare ⚪🔵, Epic up to 🟣).
- All names and looks are original; none are based on real people.

Stat order: **Aim / Reflexes / Game Sense / Teamwork / Clutch / Consistency**.

## Key player events
- **First signing**: short intro cutscene (walks into your HQ, does their vibe animation, caster line).
- **Story moments**: each key player has 1 life event in [[Player Life Events]] (e.g. Wraith's face reveal, Moss's "big match nerves", Kaito vs Nova Kaze rivalry).
- **Glow-up**: training a key player to 20+ OVR above their start unlocks a new outfit variant (e.g. Rusty gets a proper headset).

## Adding new key players
1. Pick title, rarity, role; check the table for gaps.
2. Write stats inside the rarity OVR range using role weights ([[Balance Tables]]).
3. Pick a trait allowed for that rarity.
4. Design a look that reads at phone size (one big signature item).
5. Add to `Shared/Config/KeyPlayers.lua` and the Collection Log.
