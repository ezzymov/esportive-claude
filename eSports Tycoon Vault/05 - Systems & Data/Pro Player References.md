# Pro Player References

Fictional in-game star players, each **inspired by** a real esports pro's playstyle archetype. This is a design reference so stat profiles feel authentic to fans.

> ⚠️ **IP / likeness rule.** The "Real-life inspiration" column stays **in this vault only**. Real names, nicknames, faces, signatures, team names and logos never ship in the game, its store page, thumbnails, or update notes. In-game tags **copy the style** of the real tag (length, lowercase/caps pattern, digit swap, name-based, word-based) but are a **different word**. Never a one-letter edit, digit swap or sound-alike of the real tag (no "s2mple", "donc", "ZywO0"). Copy the playstyle and the naming *style*, not the name.
>
> Rosters and teams change often. Team names below are "known for" eras, not current status. Re-check before using them in any planning.

Stat order: **Aim / Reflexes / Game Sense / Teamwork / Clutch / Consistency** (1–100). OVR uses role weights from [[Balance Tables]]. Rarity tiers follow [[Skill Levels & Ratings]].
