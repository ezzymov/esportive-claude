# Map Library

All map ideas. Rules for pools, veto and mastery: [[Maps & Map Pool]]. How maps become cutscene sets: [[Clip Cutscene System]].

Each map lists: theme, layout, pace, stat lean, and **Clip Spots** (authored areas where cutscenes happen). All names fictional; don't copy real esports map layouts or names.

## Aim Arena (5v5 tactical shooter, plant/defuse the Charge)
Two sites (A and B), a middle, and spawns. Fast pace = favors Entry; long lanes = favors Sniper.

| Map | Theme | Layout | Pace | Stat lean | Clip Spots |
|---|---|---|---|---|---|
| **Neon Docks** | Night shipping port, stacked containers, cranes, neon signs | A site on a crane platform, B site in a warehouse, long "Pier" lane in the middle | Balanced | Sniper +10%, Aim +0.05 | B Crane (jump-down plays), Container Maze, The Pier (long snipes) |
| **Old Arcade** | Abandoned 80s arcade, glowing cabinets, prize counter | Tight corridors, B site in the ball pit, A site at the prize counter | Fast | Entry +10%, Reflexes +0.05 | Ball Pit (hide/surprise), Cabinet Row (close duels), Prize Counter |
| **Skyline Mall** | Rooftop shopping mall at sunset, escalators, food court | Mid food court connects both sites, escalators as vertical routes | Balanced | Flex +5%, Teamwork +0.05 | Escalator Rush, Food Court Mid, Glass Skybridge |
| **Frostbyte Labs** | Snowy research base, glass corridors, server towers | Long glass hallways (see through), A site in the server room | Slow | Strategist +10%, Game Sense +0.05 | Server Room, Glass Corridor (shoot-through clips), Snow Yard |
| **Monorail** | Futuristic city with a moving monorail through the middle | Train passes every 30 s and blocks/opens mid | Fast | Clutch +0.05 | Train Jump (hero hops the moving train), Station Platform, Tunnel |
| **Jungle Ruins** | Ancient stone ruins, waterfall, rope bridges | A site on a temple top, B site behind the waterfall | Balanced | Consistency +0.05 | Waterfall Peek, Rope Bridge, Temple Steps |
| **Garage Grounds** *(easter egg)* | A giant version of YOUR starting garage | Tiny-player scale: run across giant keyboards and desks | Fast | — | Desk Canyon, Keyboard Bridge, Chair Tower |

*Garage Grounds:* event-only map, pulls your team's colors and logo into the decor. Great for Bloopers.

## Building rules for maps
- Every map has a **full version** (for future live views) and a **Clip Stage** version (< 2,500 parts, just the Clip Spots). Start with Clip Stages only.
- Each Clip Spot needs: 8–16 nav nodes, 4–8 cover points, 3 camera anchors, 1 hero line.
- Bright, readable colors per site (A = cyan, B = magenta) so phones can follow the action.
- Test each map's Clip Spots with every moment template before shipping.

## Launch target
Aim Arena: 5 maps (Neon Docks, Old Arcade, Skyline Mall, Frostbyte Labs, Monorail). Other titles: 2 maps each when they unlock, more per update.
